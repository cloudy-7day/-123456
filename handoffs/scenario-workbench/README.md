# 知行 · ima 本地知识库图文工作台

独立参考工作台，默认入口：http://127.0.0.1:4320/ 。先读 [队友参照说明](docs/TEAM-HANDOFF.md)。本目录未接入仓库根目录应用。

现在使用用户提供的《任德耀新建华为PC知识库(2).zip》作为 ima 知识库本地副本，**不是实时 ima OpenAPI 读取，也不从其他来源补产品事实**。

## 完整路径

客户需求理解 → 按准确型号读取本地知识库 → 原文与限制条件对照 → 生成小红书文案和3张图 → 引用/图片索引/表达检查 → 编辑与导出。

- 已索引 10 个具备“产品事实.md”的产品目录与 53 张图片；不是对全库所有内容的通用检索。
- 读取所选型号的“产品事实.md”“卖点与限制.md”，按图片索引匹配同型号素材。
- 与当前型号有关的原文发送给 DeepSeek，得到逐字引用、条件和需求对照；不发送整个压缩包或价格机密目录。
- 3 张 PNG，1080×1440，包含本地知识库配图。可单独编辑卡片文案、下载 PNG 或打包 ZIP。
- 内容包含小红书文案、3 张 PNG、原文与事实依据、图片来源、知识库包校验值和核验记录。
- 关键软件、系统和预算缺失时仍暂停适配判断；不会因为能生成内容就声称适配通过。

## 运行

Node.js 22+，安装依赖后 `npm run build`、`npm start`，默认4320。macOS 可双击 `run-local.command`，读取本目录 `.env.local`。

复制 `.env.example` 为 `.env.local` 后在本机填写自己的 DeepSeek 凭证。知识库及索引默认写入本目录 `.local/`。支持 `SCENARIO_ENV_FILE`、`IMA_LOCAL_INDEX` 指向已有私有文件；这些变量需在启动进程的环境中设置。仓库不包含密钥或知识库。

更新或迁移知识库：`python3 scripts/import-knowledge-base.py /path/to/知识库.zip`，随后重启服务。导入目录与索引留在被 Git 忽略的 `.local/` 中，不提交源代码。可设置 `IMA_LOCAL_DIR` 改变导入位置，同时在启动服务时设置相应的 `IMA_LOCAL_INDEX`。

## 状态与边界

当前资料为用户提供的 v7 本地包，产品文档标注事实基准日 2026-10-17。不会自动同步知识库更新；当前销售版本、价格、软件兼容和最终适配须另行确认。

自动检查包括客户事实引用、产品逐字依据、参数及绝对化/虚构体验检查、图片目录与索引的型号一致性、图片文件完整性。不等同于实机兼容性测试或人工审核。

未找到准确型号时明确报错，不换成相似型号。无资料预演接口仍保留用于开发，但主按钮走本地知识库完整路径。原文包含第三方内容，仅作为资料而不是可执行指令。当前未实现自动发布、跨全部目录的全文检索或持久化草稿；刷新前请先导出。

### 图片来源硬规则

营销配图仅可来自用户提供的 ima 本地知识库导出包。服务端校验登记 ID、型号与来源，并在读取时验证真实文件路径处于知识库目录内及内容摘要一致；客户端预览和导出仅允许指定的本地素材路径。来源链接仅用于追溯，不用于下载补图。不接入网络搜图、外链替代素材或 AI 生图。缺图时明确标记待补充。

### 按硬性条件筛选型号

左侧型号列表随场景与补充信息更新。明确的系统条件按 ima 本地产品事实筛选；预算、必须的软件及其他硬要求缺少直接依据时列为待核实，暂不可选。偏好不作为淘汰条件；可展开查看各型号的原因与资料位置，或更正系统和预算条件。后端生成入口也校验同一规则。

公开价格卡仅作带日期的资料线索，历史快照不视为有效报价；目前尚无已核验配置报价输入，因此有预算硬上限时会暂停型号选择，需要后续补齐有效报价及必要配件总价。软件兼容同样不从操作系统相同推定。无可选型号时仍可整理和保存客户洞察。当前完成确定性硬条件筛选，不自动排序或代选产品，也不代替完整适配判断。
