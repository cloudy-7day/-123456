# 华为门店助手 · 90 秒演示视频

面向复赛评委的第一版审片视频，采用宣传片引入、实际页面操作采集和图文成品展示，配中文合成旁白与字幕。成片为 1920×1080、24fps、90 秒，约 11 MB。

## 视频讲什么

从“每天背电脑挤地铁，想轻一点，又担心软件不好用”的通勤场景出发，展示店员怎样输入需求、选择介绍型号和门店帮助，再由后台理解、检索与核验，交付封面、三张图卡、正文和咨询回复。

重点是操作简单、需求有据、素材可用。没有把向量搜索当作已验证优于关键词的卖点，也没有承诺实际引流或成交提升。

## 制作方式

- 输入操作通过实际页面逐帧采集；其余界面和图文来自本地运行中的项目及本次真实生成结果。
- 页面操作与生成等待经过剪辑，视频标注“流程节选”，不代表原始模型生成耗时。
- 画面、字幕和旁白先按九段分镜渲染，再在 OriginCut 中组装为九段画面及九段对应原音轨的可编辑时间线，最后由 OriginCut 原生导出。
- 中文声音为 macOS Tingting 合成旁白，本版用于内部审片；未克隆真人声音。字幕已烧录进画面，同时附独立 SRT。
- 产品图片来自原项目提供的知识库。通勤客户是演示场景；发布前仍需核对具体配置、软件和门店实际服务。

本目录提供成片、封面、脚本、字幕、分镜和检查记录。完整原生工程及源素材保留在制作电脑上的独立 OriginCut 项目中。此视频是辅助演示材料，比赛要求的现场运行仍需实际执行。
