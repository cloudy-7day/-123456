## 这版做了什么

以 cloudy-7day 2026-10-23 上传的最终代码 `eb1df5bb280b108e5af0ce787e5851ea3cb8bb26` 为基座，保留完整应用代码，只新增视频交付目录。

队长原视频约 7 分 14 秒，是无声操作录屏。新版压缩为 3 分钟，沿用学生“小组汇报”案例：输入场景、理解需求、选择产品、后台生成、小红书图文、配图、查看来源与核验、复制使用。

大部分画面来自队长实录，压缩等待和重复浏览；产品指定画面来自本机运行的最终版。片中标注“实际操作节选 / 等待已压缩”，不代表一次生成只需演示中的时间。此次核对了代码、构建与界面，没有重新发起完整模型生成，也没有修改应用功能。

## 配音怎么改了

换成中文神经配音 `zh-CN-XiaoxiaoNeural`。它是合成语音，不是真人录音，也没有模仿队长声音。全片使用一条连续 48kHz PCM 旁白，再统一编码为 AAC；画面围绕旁白时长剪辑，没有分段变速、反复拼接、重复叠音。未加入背景音乐，避免掩盖讲解。

使用 [edge-tts](https://github.com/rany2/edge-tts) 访问在线语音服务；[微软中文语音资料](https://learn.microsoft.com/azure/ai-services/speech-service/language-support?tabs=tts)。

## 本次检查

OriginCut 原生时间线为11段视频加1条连续旁白，精确180秒，10个切点无空隙。自动语音核对覆盖全部11段，60秒和120秒附近的疑似识别重字经独立短片复查未复现。导出音频与源WAV每5秒抽取1秒波形比对，35个窗口最小相关性0.999868、延迟均为0；没有中途超过0.8秒的静音。全片解码检查未见错误，未检测到黑帧。未进行人工听审，不把识别检查冒充真人听感评价。

原生导出保留在制作电脑，GitHub版仅降低视频码率方便下载，1080p/30fps保持不变，AAC音轨直接复制，不重新拼接或转码。
