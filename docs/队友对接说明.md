# 队友对接说明 · 最终维护入口

当前约定以根目录 README.md、contracts/input.schema.json、contracts/output.schema.json 为准。旧交付包不再作为可运行版本保留。

- 输入同学维护 modules/scenario/server、shared 以及输入相关 React 组件。一段完整原话提取为事实、推断、未知与冲突；保留来源和修订顺序，不补造预算或软件事实。
- 输出同学维护 prompts、contracts/output.schema.json 和 ResultView.jsx。完整输出字段为 customer_insight、strategy、content、image_plan、source_refs、pending_confirmation；页面与文本导出交付完整小红书文案和配图，不恢复分时店员脚本。
- 集成同学维护 src、server.mjs、Handoff.jsx、公共入口、构建与部署脚本。更改共享字段时同步修改模型提示词、服务端校验、展示及测试。

产品和图片从同一知识库型号读取。手动选型也要满足客户明确的系统要求；预算、软件等未知信息继续保留，不阻断有限草稿。

合并前在根目录运行 pnpm test、pnpm build，再运行 tests/browser/focused-flow.mjs。异步生成须检查 NDJSON 最终 result/error，不以 HTTP 200 判断成功。

魔搭包通过 pnpm package:modelscope 生成。不要修改生成目录，也不要提交密钥或历史输出。GitHub 对比及本轮测试结果见 docs/upstream-comparison.md。
