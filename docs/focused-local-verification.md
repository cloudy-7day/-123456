# 校园学习与本地资料包联调

本记录覆盖本轮单输入、单渠道和本地知识库调整，取代旧的缓存资料运行说明。未推送 GitHub，未更新魔搭；原 8787 服务保持运行。

## 用户流程

校园学习标签 + 小红书渠道 → 一段完整输入 → 自动提取维度 → 可展开/收起的理解摘要 → 确认需求和具体型号 → 完整文案与店员演示脚本。

当前只开放校园学习与小红书。场景标签只控制发布方向，不是客户事实来源。人物身份、任务、限制及型号意向均从完整输入提取。编辑完整输入会清除此前的补充和确认，防止前一位客户的条件污染新任务。

最终可见交付是文案（标题、正文、行动引导与配图）和店员脚本；画像、策略及核验依据收在可展开区域。脚本约 3 分钟，分 0—30、30—90、90—150、150—180 秒，每段写店员说、店员做、检查点和异常处理。复制和文本导出均可用。后端保留八字段接口供队友对接。

## 知识来源

- 用户资料包：`华为PC知识库(2).zip`。
- 知识库：`华为PC全板块深度知识库_v7`。
- 原包 SHA256：`08fe08379dd2ca136f04a0971e8edc42cf2db66e8231cec638cf77cbc76de706`。
- 导入全部 1,522 个文件；10 个产品，68 张具有产品索引的图片。
- 原路径、内容哈希与产品目录保存在 `knowledge/catalog.json`，资产保存在 `knowledge/assets/`。
- 仅从明确选定的型号及系统目录读取原文和图片；相近型号或不明确的系统拒绝自动匹配。
- 图片来自压缩包原图，不访问网络图片地址；检查内容哈希和图像格式后复制为可展示文件。
- 默认 `KNOWLEDGE_SOURCE=local`，不需要 ima 凭证，不调用 ima；历史兼容模式只在主动配置时使用。

## 部署与边界

`pnpm package:modelscope` 将运行代码和 `knowledge/` 打入 `modelscope-upload/`；排除密钥、缓存、历史生成结果、本地依赖与测试文件。Docker 使用 Node.js 24，监听 0.0.0.0:7860，构建时编译前端。必填变量仅 `DEEPSEEK_API_KEY`；建议 `DEEPSEEK_MODEL=deepseek-flash`。不需要上传压缩包本体或个人 ima 配置。

本机尚未运行 Docker 镜像构建，线上也尚未同步。模型只使用图片元信息，没有读取像素；图片格式、来源和目录校验不能替代人工检查画面。文案是草稿，没有宣称逐句事实或合规审查已通过。另有两个产品仅有两张索引图片，会显示真实缺口，不跨型号凑图。
