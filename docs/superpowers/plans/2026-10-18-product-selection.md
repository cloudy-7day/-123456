# 产品候选与华为门店界面 Implementation Plan

> **For agentic workers:** Use executing-plans to implement task by task, preserving the current local service workflow.

**Goal:** 保留指定产品测试能力，增加有资料依据的可修改候选，以简洁华为品牌界面呈现。
**Architecture:** 本地目录提取有限规格与原图预览；共享选择器按明确任务匹配候选，原输入意向优先。前端在生成前可指定产品，生成后展示依据与替换入口。
**Tech Stack:** Node.js 24、React、Vite、现有知识库与Playwright。

## Constraints
- v4第5、9页要求产品输入与指定产品测试；自动选型为辅助，不宣称必需评分项。
- 华为标识、库内原图，参考Apple产品卡片与清晰层级；不引入Apple品牌素材。
- 无价格保证、软件兼容结论或伪造匹配分；保留未知与引用。
- 仅本地8791，8787和线上不变。保留八字段输出与校园/小红书单选。
