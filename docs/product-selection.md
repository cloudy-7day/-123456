# 产品选择与页面调整

## 赛题依据

用户提供的《华为·产业进阶赛道·赛题手册v4》：
- 第5页“任务输入”：输入产品、目标人群、场景和发布渠道；信息不足时提示补充。知识检索现场检查包含更换产品。
- 第9页“统一测试任务”：基础生成输入“指定产品 + 人群 + 场景 + 平台”。
- 没有要求必须实现自动选型。因此保留人工指定作为基本能力，候选匹配是辅助功能，不声称有独立加分或保证适配。
- v4仍明确要求ima资料与图片。本地资料包是用户因接口额度限制选择的当前实现，尚不能据此断言满足ima接口检查；提交材料需如实说明，规则是否接受由主办方确认。

## 当前选择逻辑

生成前可选“按需求推荐”或“指定产品”。指定产品覆盖本轮营销任务对象，单独标记为操作员选择，不改写客户原话。没有手动指定时，原文中能唯一匹配的产品优先；否则按明确任务匹配知识库中已验证的特征。原文歧义或无匹配不随便指定，可从目录选择后继续。

匹配支持携带、屏幕/大屏、键盘、OLED、手写笔、隐私和折叠形态。证据由产品事实文档提取，保留具体资料型号与配置限定。展示最多3个候选及理由；排序使用匹配特征数量，同分按目录顺序，不是性能排名。仅排除明确系统限制，其他硬条件仍需核验。没有价格数据库，因此不做预算最优计算，不保证软件兼容、AI性能或四年使用体验。

型号和系统校验仍由本地检索执行。手动选择只解除产品意向歧义；预算或其他原话冲突仍须先解决。切换选择方式或产品清除旧生成结果，生成期间锁定输入。

## 前端与接入位置

- `modules/scenario/src/main.jsx`：完整输入、选择方式、前置指定产品。
- `modules/scenario/src/Handoff.jsx`：候选理由、选型来源、替换候选和生成。
- `modules/scenario/src/ProductCard.jsx`：产品原图、特征、展开查看来源；缺图不借图。
- `modules/scenario/src/store-design.css`：浅灰/白背景、华为红、分层标题和响应式产品卡。
- `modules/scenario/shared/product-suggestion.mjs`：明确事实与资料特征匹配、系统限制、歧义处理。
- `src/product-profile.mjs`：从已校验产品事实提取有限特征。
- `GET /api/products`：保留原字段，新增`features[{id,label,evidence,source_path}]`与`preview:{url,title,path}|null`。
- `GET /api/product-image/:id`：严格产品ID、归属及哈希校验，直接返回库内原图。

设计参考 https://www.apple.com/mac/ 的产品展示层级、留白和选择入口；页面使用华为产品、华为红和参赛作品标识，不使用Apple品牌图像。

## 验证

浏览器合成回归覆盖：自动候选、原文型号不明确后手动选择、生成前指定型号、选择来源不冒充客户原话、切换清除旧结果、生成锁、复制、导出、手机布局。真实资料目录10个产品中9个有清晰预览；Fold现有素材被标记模糊，预览留空。

真实DeepSeek校园输入完成：未额外补齐软件或学校算力；按携带/键盘等证据准备 `HUAWEI MateBook 14（鸿蒙版）` 草稿候选（不代表编程适配结论），得到小红书完整文案、3张原图及店员脚本。复制、导出、图片加载与手机布局通过，无浏览器错误。忽略目录 `output/product-selection-verification.json` 与 `product-selection-events.json` 保存本机证据。
