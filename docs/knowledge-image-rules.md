# 知识库与配图接入规则

完整资料包已导入 `knowledge/catalog.json` 和 `knowledge/assets/`，保留原始路径与 SHA-256。部署包与 Docker 镜像包含这两部分，运行时无需访问原电脑的 ZIP，也不调用 ima。魔搭仍需配置 `DEEPSEEK_API_KEY`。

检索顺序：完整产品型号与系统版本 → 该产品目录的原文和图片索引 → 场景关键词匹配图片标题/描述 → 校验原图字节与文件格式 → 返回最多6张不重复的候选原图 → 模型按文案选图。

场景匹配规则在 `src/local-knowledge.mjs` 的 `imageTopics`：携带/图书馆对应轻薄机身；编程对应键盘；阅读对应屏幕；手写对应触控；协作对应互联；外接对应接口。没有匹配词时保留原索引顺序，清晰原图优先。匹配仅依赖资料描述，不代表视觉识别或兼容性验证。

模型配图规则在 `prompts/image-rules.txt`，由 `src/pipeline.mjs` 每轮加载。改规则文件后重新生成即可；改检索代码后重启服务。新增场景可扩充关键词映射，新增发布渠道同时修改输出张数检查与提示词。

仅使用所选产品知识库原图，保留来源；不跨型号借图，不生成替代图片，不编造路径，不重复凑数。小红书建议至少3张；缺图明确提示。文件校验失败则跳过该图。产品事实仍以文本证据为依据。

更新资料包时运行导入脚本并检查生成目录，再运行 `npm run package:modelscope`，将重新生成的 `modelscope-upload` 文件夹上传魔搭。打包排除密钥、缓存、历史输出和本地运行状态；原始知识库图片属于必需资源，会保留。
