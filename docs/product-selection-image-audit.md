# 产品主图与推荐筛选修复

本地验证日期：2026-10-22。服务端口 8792；未推送 GitHub 或魔搭。

## 原因与调整

旧推荐按命中特征数量排序，同分使用目录先后顺序。原有两个示例都主要表达阅读和记录，因而容易推荐同一款。现按明确系统要求过滤，再对有原文支撑的需求匹配加权：通用阅读、输入各 1 分；便携、OLED、手写、隐私、触控、数字键盘各 3 分；大屏和折叠各 4 分。原话明确表达“最看重、首要、优先、更在意、最重要”时，该需求权重加倍。

分数不是性能、性价比或购买价值排名。未知、推断及否定需求不加分；产品功能缺原文依据不加分。没有需求不按职业强推。明确指定型号仍优先，系统限制冲突仍拦截。同分按型号名称稳定排列，并明确显示同分，不宣称唯一最优。更改目录顺序不改变结果。

页面“为什么推荐这款？查看筛选过程”展示筛选数量、需求权重、前三个候选、命中依据与未命中项。每项依据可展开查看需求原话与产品摘录。未命中资料不代表产品一定没有该能力。

两个虚构示例的选型偏好已写进可编辑输入和入口说明：学生侧重携带、触控翻阅；会议侧重 Windows、大屏与数字录入。推荐函数不接收职业示例 ID，不内置“学生必须某款”的映射。

## 图片规则

旧主图按“外观”等文件名关键词选择，文件名实际存在错标：D 16 SE 的“精致外观”是芯片；D 16 只有芯片和协同图标；X 系列只有人物广告图。已查看全部原图缩略图，并对补充原图单独查看。

- 每个型号指定至少一张核对过的电脑主图，当前 10/10。
- 每张图片在 `knowledge/catalog.json` 中保存与 SHA-256 绑定的 `visual_review`。主图必须 `allowed=true`、`preview=true`、`role=product`。
- 运行时只检索审核允许的画面；人物广告、芯片、纯图标、空白屏幕素材保留原文件，但不进入自动主图或配图。
- 用画面复核标签替代误导的标题供检索；目录归属、文件哈希和格式校验继续执行。
- 画面复核只确认产品与视觉用途，不证明功能、系统兼容或性能。文案仍走知识库原文核验。
- 新增图片保留官网页、原图地址、导入时间与 `official-supplement` 来源，不冒充原 ZIP 自带图片。
- 近似图片仍按指纹与视角分组去重。新增资产后运行 `python scripts/rebuild-image-fingerprints.py` 重建指纹；文件内容变更会使旧复核失效。

补充 5 张原图的官方页面：[MateBook D 16 2024](https://consumer.huawei.com/cn/laptops/matebook-d-16-2024/)、[MateBook D 16 SE 版 2024](https://consumer.huawei.com/cn/laptops/matebook-d-16-se-2024/)、[MateBook X Pro 酷睿 Ultra 微绒典藏版](https://consumer.huawei.com/cn/laptops/matebook-x-pro-ultra-premium-edition/)。原图地址逐张记录在资产目录中。
