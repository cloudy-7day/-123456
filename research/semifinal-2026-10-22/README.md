## 当前结论

首批建议以“学生：课程资料到小组汇报”和“职场协作：会议到行动项及方案”为两个业务任务方向。它们是根据已有渠道研究和任务差异选出的演示候选，不是华为 PC 职业购买人数前两名。仍未取得可靠的华为 PC 实际购买者职业占比。

学生场景可以继续使用寝室、图书馆、教室，用同一份作业或汇报串起来。地点是情境，真正选择产品能力的依据是任务。医生、律师等入口可保留，但需要继续验证各自任务及对应型号证据。

分类已经包含功能能支撑什么任务、哪些条件限制表达、哪些说法不能承诺。具体 SKU 商城售价仍缺可靠数据，不能据此声称已经实现精确预算选型。已有 68 张知识库图片已复核文件哈希；本轮没有新增下载商城图片。

小红书案例的量化结果来自参与方自报，不证明单靠文案带来增长；尚缺华为 PC 直接案例。未经核实的联想案例及引用该案例的模式，已经从默认素材检索中排除。营销案例只能支持表达选择，不能支持华为产品功能、销量承诺或客户画像。

本地资料包替代 ima 已由用户确认获允许。本地生成流程现已接入逐段知识库辅助核验：独立模型判断主张与原文的关系，程序检查句段覆盖、来源、精确摘录和数值。此结果不是人工认证，不能等同于完整营销合规审核。

## 如何复建和检索

在当前文件夹运行，使用 Python 标准库，无新增依赖：

```powershell
python build_database.py
python build_database.py --query 学生 汇报 资料 --dataset audience --limit 3 --full
python build_database.py --query 会议 行动项 --dataset audience --limit 3 --full
```

默认查询只返回允许作为候选材料的记录，完整材料仍带证据状态与适用范围。关键词匹配分数只表示命中词数，不是匹配概率。`--full` 同时返回材料正文和来源，供后续生成器使用；它没有调用模型，也没有修改客户事实。

核验结果：数据库完整性与外键检查通过；68 个本地图片哈希通过；4 组检索返回非空，未包含排除来源，均保持 customer_facts 为空。主代理另复核了校园人群报道、部分官方产品规格和三个营销案例公开页面。并未逐一重新联网核验所有存档段落。

## 完成范围

研究资料已接入本地学生、职场会议的小红书流程。页面提供两类示例、成稿及配图，并可展开研究依据和逐段核验记录。研究数据库为只读检索，产品功能仍以具体型号的本地产品原文为准。朋友圈和店员后续跟进指南仍未接入本轮界面。
