## 可检索表达库如何使用
JSON包含5个case、10个writing_pattern、10个acceptance_rule。writing_pattern均标为 researcher_design_recommendation，具有任务词、营销阶段、内容目标、反例和迁移限制。观察事实保存在case，设计建议另存，避免将推导当来源原话。缺指标为null。

建议检索顺序为：用户本次任务和障碍→营销阶段→内容目标→职业语言；职业标签不能覆盖实际输入。每次选择2—3项模式形成完整文章，不把全部模式逐项展示给读者。案例ID是研究引用，不能替代当前型号[S编号]产品证据。

| 模式 | 适用阶段／目标 | 设计建议与不可套用的情况 |
| --- | --- | --- |
| XP01 任务卡住的一刻 | 认知、考虑／共鸣 | 用材料和动作开场；不编病例、案件和亲测经历 |
| XP02 同一交付物推进 | 考虑／理解、收藏 | 同一份成果经历整理、讨论、展示；不能只换三个地点 |
| XP03 一段一个帮助 | 考虑／产品理解 | 动作→障碍→有据功能；不推断专业判断或全行业兼容 |
| XP04 看得见的证据位 | 考虑、决策／可信 | 真图只说明其可见内容；不冒充现场实录或效率测评 |
| XP05 CTA匹配目标 | 认知至决策／评论、咨询 | 互动问具体任务，咨询须真实入口；不造优惠或活动 |
| XP06 一篇承担一个阶段 | 全阶段／目标一致 | 认知抓任务、考虑讲证据、决策补确认依据；不把曝光当成交 |
| XP07 职业任务分流 | 认知、考虑／相关性 | 材料与协作动作随职业变化；不能全员套写报告 |
| XP08 标题承诺可兑现 | 认知／点击后匹配 | 标题和正文解决同一摩擦点；无“必备”“三分钟搞定一切” |
| XP09 型号服从叙事 | 认知、考虑／自然 | 一次自然交代型号，功能跟随动作；不删必要条件扩大主张 |
| XP10 朋友圈关系重写 | 后续渠道适配／交流 | 重建分享缘由、关系和引导动作；不止删字或伪造个人体验 |

推荐开头示例属于自拟设计：“如果你也要把几轮批注合成会前一稿，最怕的可能不是写，而是找错版本。”后文只能接当前型号已经证明的功能；这句话本身不证明电脑能合并版本或自动审查。

视觉建议亦属于设计推导，并非对原始博主笔记逐图复原。封面突出一个任务问题，后续图承担各段证据；只有产品图时保持产品图身份，用正文解释任务。不得伪装科室、律所、课堂实拍，不从产品图推导软件操作。没有合适真图便标缺口，不强凑场景图。

当前生产提示词的CTA以互动为主。本研究为后续设计记录目标差异：认知可问任务共鸣，考虑可引出具体疑问，咨询/购买目标必须有真实可用且已获授权的路径。不能凭研究包自动添加门店、福利、优惠或发布动作。

## 成稿验收建议
以下是本项目建议，非平台官方算法阈值或爆款保证。程序检查只验证形式；语义和视觉仍需审阅。

| ID | 验收标准 | 检查类型 |
| --- | --- | --- |
| XA01 | 六字段可解析，引用标记有效且属本轮 | 可程序检查 |
| XA02 | 约20字标题、400—600字正文、自然emoji与少量相关话题 | 可程序提示，风格越界非平台违规结论 |
| XA03 | 每个产品主张由当前型号文本证据支持 | 需语义审核；引用存在仅是程序前置 |
| XA04 | 身份和任务忠实，不编购买、亲测与职业经历 | 需语义审核 |
| XA05 | 2—3段围绕同一成果，动作有推进且职业具体 | 需语义审核 |
| XA06 | 功能融入动作，无参数堆砌、空泛口号和无证据效率数字 | 需语义审核 |
| XA07 | 条件完整放辅助字段，正文必要短限定且不扩大范围 | 需语义审核 |
| XA08 | 真图、型号、图文一致，无现场/操作伪装，裁切清晰 | 需人工判断，可程序辅助型号匹配 |
| XA09 | CTA与任务和目标匹配，入口真实，不重复已知问题或索取敏感资料 | 需语义审核 |
| XA10 | 整篇自然可信；分别评价阅读、收藏/有效评论、可归因咨询 | 需人工判断 |

当前基线规定的400—600字、型号出现一次、2—4个emoji，是项目风格选择，不能包装为小红书官方成功公式。效果测试也应分别记录曝光/阅读、收藏与有效评论、可归因咨询/成交，标清观测窗口、花费、归因口径；点赞不是购买，历史案例不担保未来结果。

## 后续朋友圈适配
朋友圈需要先确认发布者身份、分享缘由、熟人关系和实际想促成的动作，再重组文章。保留最贴近该人群的一条任务及必要证据，减少陌生人搜索标签和公域征集语气，改为熟人能回应的话题或真实咨询入口。只有已提供且获授权的个人经历才能写“我用过”；品牌代写依然用客观或条件式表达。重写后仍需复核型号、事实、图像身份、条件和引导路径，不是把小红书删短后直接贴过去。
